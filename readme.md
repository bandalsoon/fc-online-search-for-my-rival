# FC ONLINE Search For My Rival

## 프로젝트 소개

FC ONLINE 넥슨 Open API를 이용한
「새로운성연합 vs 피버슛」 개인 경기 아카이브.

## 개발 목표

- 두 유저의 상대전적 확인
- 경기별 결과 및 상세 기록
- 유저별 승/무/패 통계
- 선수별 득점 및 활약 통계
- 상대전적 기반 다양한 기록 및 통계
- 향후 새로운 경기 자동 업데이트

## 개발 순서

- [ ] 넥슨 Open API 연결
- [ ] 유저 식별자 조회
- [ ] 매치 데이터 조회
- [ ] 두 유저의 상대 경기 필터링
- [ ] 승/무/패 계산
- [ ] 경기 상세 페이지
- [ ] 선수별 통계
- [ ] 전체 전적 대시보드
- [ ] UI 디자인 개선
- [ ] 배포

## Players

- 새로운성연합
- 피버슛
